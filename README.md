# BabiBot Mobile: εκδόσεις

Εδώ βρίσκονται οι εκδόσεις (APK) του BabiBot Mobile για Android. Η εφαρμογή ελέγχει μόνη της για νέα έκδοση και την εγκαθιστά από εδώ.

**Πρώτη εγκατάσταση:** κατεβάστε στο κινητό το
[BabiBot.apk](https://github.com/WantedHool/BabiBot-Mobile-releases/releases/latest/download/BabiBot.apk),
που είναι πάντα η τελευταία έκδοση.
